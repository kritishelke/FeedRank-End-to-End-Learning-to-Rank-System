# FeedRank

FeedRank is a production-style news feed ranking dashboard based on the MIND recommendation dataset brief. It presents candidate generation, leakage-safe feature engineering, model comparisons, grouped ranking metrics, cold-start diagnostics, class imbalance analysis, and offline policy simulation in one usable interface.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
